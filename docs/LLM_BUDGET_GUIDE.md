- Installing **Ollama** for free local models (all iterative development happens there)
- The provider-abstraction pattern used from Module 4 onward (one interface, API ↔ local fallback)
- Tracking spend per module (budgets: M4 ~€3, M5 ~€4, M6 ~€5, M7 ~€6)
